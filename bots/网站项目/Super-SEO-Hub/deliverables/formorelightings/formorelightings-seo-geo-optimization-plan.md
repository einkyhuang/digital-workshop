## 3. 主题集群与内链规划（五簇）

**锚文本原则**
1. 商业页锚文本用「品类+能力」组合（如 *magnetic track light supplier*、*OEM LED lighting manufacturer*），避免裸关键词堆叠。
2. 支撑文章→商业页用 1 个精确锚 + 1 个自然句内链，单页外链出站锚文本不重复超过 2 次。
3. 所有支撑文章底部固定「Related products / Work with us」回流区块（2–3 条）。
4. 枢纽页向下链支撑文章用描述性锚（*learn how to choose CRI*），支撑文章向上链枢纽用短锚（*solar street light solutions*）。
5. 禁止跨簇乱链；每篇文章至少 1 条入链（来自枢纽或同簇支撑）。

## 4. GEO 专项动作

| 动作 | 具体实施 | 验收标准 |
|---|---|---|
| **llms.txt** | 根目录 `/llms.txt`：站点简介、核心实体（Formore Lighting、产品线、工厂能力）、重要 URL（Products/Sourcing/OEM-ODM/Solutions/Insights 枢纽）、联系与合作方式 | 可 200 访问，内容与站点一致，含 5 簇 URL |
| **sameAs** | Organization schema 增加 sameAs：LinkedIn、YouTube、Alibaba/Global Sources（如有）、行业目录、Google Business（如有） | Rich Results 校验零错误 |
| **FAQPage** | 每个产品线页 + 每篇支撑文章至少 3 组 Q&A，FAQPage schema 与可见内容一致 | 抽检 10 页全部通过 |
| **BLUF** | 每篇文章首段 40–60 词直接给结论（是什么/怎么选/推荐参数），再接细节 | 12 篇新文 100% 具备 |
| **列表/表格** | 参数对比（CRI、色温、UGR、光束角、功率）用表格；选型步骤用有序列表 | 每篇 ≥1 表或 ≥1 列表 |
| **权威引用** | 引用 IES/CIE/ENERGY STAR/DLC/UL 等标准与数据，附来源链接；避免无出处断言 | 每篇 ≥2 条外部权威引用 |

## 6. 内容生产交接口径

### 6.1 Brief 必填字段（SEO 专家 → 墨墨）
| 字段 | 要求 |
|---|---|
| 标题（H1） | 含主关键词，≤60 字符，商业意图明确 |
| H2 大纲 | 4–7 个 H2，覆盖 BLUF、参数表、选型步骤、FAQ |
| 关键词 | 主词 1 + 次词 2–3 + 长尾 3–5（标注量级/未收录） |
| 内链 | 入链 2–3 条（锚文本+URL）、出链 2–3 条（回流商业页） |
| FAQ | ≥3 组 Q&A（与 FAQPage schema 一致） |
| Schema | 文章用 Article/BlogPosting；产品页 Product；FAQPage；Organization sameAs |

### 6.2 交付流程
1. SEO 专家在 Issue/文档出 Brief（含上述字段）。
2. 墨墨写**英文成稿**，草稿进分支 `seo-drafts` 的 `content/insights/drafts/`（命名：`YYYY-MM-DD-slug.md`）。
3. SEO 专家审稿（关键词覆盖、内链、FAQ、schema、BLUF、引用），返回修改意见。
4. 定稿后由用户批准，合并 `main` 并发布；发布后更新 sitemap 与内链台账。
