# Desktop「超级工作台.app」反复重启 — 排查与修复

时间：2026-10-30（Asia/Shanghai）

## 结论（根因）

**根因：内嵌 MagicHub 的 `MagicHubBridge.saveSettings` 在收到不可 JSON 序列化的 JS 对象时，调用 `JSONSerialization.data(withJSONObject:)` 触发 ObjC 异常；该异常不会被 Swift `catch` 接住，进程直接 `SIGABRT`。**

证据：

| 项 | 内容 |
|---|---|
| 崩溃报告 | `~/Library/Logs/DiagnosticReports/超级工作台-2026-10-30-022600.ips`（生产 `com.ky.superworkbench`） |
| 时间 | 2026-10-30 02:25:23 +0800 |
| 路径 | `/Users/ky/Desktop/超级工作台.app/Contents/MacOS/超级工作台` |
| 栈 | `NSJSONSerialization dataWithJSONObject` → `MagicHubBridge.saveSettings` → `dispatch(save-settings)` |
| 同类 -dev | `超级工作台-dev-2026-10-30-022816.ips` 同一栈 |

当用户切到「外贸工作台」加载 MagicHub 后，前端频繁 `save-settings`；一旦 payload 含非法类型即闪退。若系统「重新打开窗口」或用户点 Dock，会表现为**反复重启**。

## 排除项（已核对）

| 检查 | 结果 |
|---|---|
| Desktop 包是否被覆盖 | **否** — mtime 仍为 **2026-10-30 02:22:10**（Asia/Shanghai） |
| LaunchAgent / login item | **无** `com.ky.superworkbench*`；login items 无超级工作台 |
| `build-dev.sh` | 只写 `/tmp/超级工作台-dev.app` + `mac-app/超级工作台-dev.app`，**不** ditto/`open` Desktop |
| `build.sh` | 只写 `mac-app/超级工作台.app`，**不**自动上 Desktop；已加拒绝 `--desktop` |
| FSEvents FeedWatcher | 仅刷新 feed 索引，**不** exit/relaunch |
| git hooks | 无 post-merge 重建/启动 |
| 生产进程 | 排查时 **未在运行**；`-dev` 已按 **精确 PID** 结束（未用 `pkill` 名匹配） |

## 修复（代码已提交，未替换 Desktop）

1. `MagicHubBridge.saveSettings`：先 `jsonSafe` + `isValidJSONObject`，非法则返回错误，**禁止**抛 ObjC 异常。
2. `build-dev.sh`：拒绝任何 Desktop 路径；可执行文件名固定 `超级工作台-dev`；bundle id `com.ky.superworkbench.dev`。
3. `build.sh`：禁用 `--desktop` 自动上桌面。

**未** 对 `~/Desktop/超级工作台.app` 做替换 / `open` / `pkill`。生产包仍是 02:22:10 那一版；JSON 崩溃修复需等用户批准的**一次性** Desktop 替换后才进生产。当前生产若再开外贸/MagicHub，**旧包仍可能崩**——请先不要依赖旧包跑 MagicHub，或批准替换。
