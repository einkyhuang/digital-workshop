# 外贸工作台双侧栏合并（Mac + Web）

## 目标
外贸模式下合并工作台侧栏与 MagicHub 侧栏为 **一层**：保留千问风格「超级工作台｜外贸工作台」切换；其下仅 MagicHub 菜单；隐藏 MagicHub 自带 aside；外层经 bridge 路由并同步 active。

## 改动要点
- MagicHub：`?embed=1` / `data-sw-embed` / Mac host → 隐藏 aside；`window.__swSetTab` + `tab-changed` / `postMessage`
- Mac：`MagicHubNav` + `SidebarView` 外贸菜单；`MagicHubWebView` embed 加载与 tab push/sync
- Web：`#tabs` 渲染 `MAGICHUB_NAV`；iframe `embed=1&tab=`
- 仅 `-dev` 构建；不改 Desktop 生产包
