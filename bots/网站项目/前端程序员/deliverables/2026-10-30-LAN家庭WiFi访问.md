# 超级工作台 · 家庭 Wi‑Fi LAN 访问

## 目标
手机连家里 Wi‑Fi 访问 Mac 上完整工作台（含本机 private），**不暴露公网**；**不改 Desktop 生产包**。

## 部署
| 项 | 值 |
|---|---|
| LaunchAgent | `com.ky.superworkbench.lan` |
| plist | `~/Library/LaunchAgents/com.ky.superworkbench.lan.plist` |
| 监听 | `0.0.0.0:8787`（拒绝非 RFC1918） |
| 口令文件 | `超级工作台应用/data/private/lan/passcode`（chmod 600，不进 git） |
| LAN URL | （安装后填写）`http://192.168.x.x:8787/` |

## 安全
- Session Cookie `sw_lan_sess`（HttpOnly）
- 无端口转发 / 隧道
- private 仅登录后可读；git 仍 ignore `data/private/`
