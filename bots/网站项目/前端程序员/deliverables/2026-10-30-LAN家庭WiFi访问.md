# 超级工作台 · 家庭 Wi‑Fi LAN 访问

时间：2026-10-30（Asia/Shanghai）

## 目标
手机连家里 Wi‑Fi 访问 Mac 上完整 Web 工作台（含本机 `data/private` 经登录后 API/静态），**不暴露公网**；**不改、不重启 Desktop 生产包**（PID 40812 保持）。

## 部署结果

| 项 | 值 |
|---|---|
| LAN URL | `http://192.168.1.4:18787/` |
| LaunchAgent | `com.ky.superworkbench.lan` |
| plist | `~/Library/LaunchAgents/com.ky.superworkbench.lan.plist` |
| 口令文件（仅路径） | `~/Library/Mobile Documents/com~apple~CloudDocs/超级工作台/超级工作台应用/data/private/lan/passcode`（chmod 600，gitignore） |
| 监听 | `0.0.0.0:18787`；拒绝非 RFC1918/本机客户端 |
| Session | Cookie `sw_lan_sess`（HttpOnly） |
| Desktop 生产包 | **未改动**（mtime 仍 03:37，PID **40812**） |

端口说明：默认曾试 `8787`，与本机 `cc-connec` 抢 `127.0.0.1:8787`；已改为 **18787**。

## 手机用法
1. 连同一 Wi‑Fi  
2. Safari 打开 LAN URL，输入口令（见口令文件）  
3. 分享 → **添加到主屏幕**（已有 manifest / apple-touch-icon / apple-mobile-web-app meta）
