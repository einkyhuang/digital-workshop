## 6) 剪辑模板与标准

### 6.1 成片规格

| 项 | 标准 |
|---|---|
| 画幅 | **9:16**，1080×1920，30fps |
| 时长 | **30–90 秒**（主帖 45–75s；测帖钩子 30–40s） |
| 视频码率 | H.264，CRF≈18–22；音频 AAC ≥192kbps |
| 前 3 秒钩子 | 必须有：冲突对白 / 大字钩子 / 强表情之一；禁止慢热空镜开场 |
| 结尾卡点 | 悬念句或黑场大字 +「Parte 1 / Sigue en el perfil」类引导 |
| 安全区 | 字幕距底边 ≥150px；避开 TikTok 右侧按钮区 |

### 6.2 ffmpeg 命令模板（完整脚本见 `tiktok_cut.sh`）

```bash
# 时间切片（秒）
./tiktok_cut.sh cut   /workspace/media/tiktok/A号/raw.mp4 12.5 75 /workspace/media/tiktok/A号/out/cut.mp4

# 强制 9:16（不足加黑边 / 过宽居中裁切）
./tiktok_cut.sh v916  input.mp4 out_916.mp4

# 前 3 秒钩子预览
./tiktok_cut.sh hook  input.mp4 hook3.mp4

# 烧录底部字幕
./tiktok_cut.sh sub   input.mp4 "Un año. Solo un año…" out_sub.mp4

# 一键：切片 + 竖屏 + 字幕
./tiktok_cut.sh all   raw.mp4 12.5 75 "¿Amor o venganza?" final.mp4
```

等价手写示例（竖屏裁切）：

```bash
ffmpeg -y -i in.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,setsar=1,fps=30" \
  -c:v libx264 -crf 20 -c:a aac -b:a 192k -movflags +faststart out_916.mp4
```

### 6.3 字幕样式

| 项 | 规范 |
|---|---|
| 字体 | 粗体无衬线（DejaVu Sans Bold / Montserrat Bold；可用 `TIKTOK_FONT` 指定） |
| 字号 | 相对 1080 宽约 **44–52**（主字幕 48） |
| 颜色 | 白字 `#FFFFFF` |
| 描边 | 黑描边 2–3px（或半透明黑底条） |
| 位置 | 水平居中，垂直距底 **≈180px**（Alignment 底部） |
| 单行字数 | ≤28 西语字符；超长拆两行，行距紧 |
| 高亮 | 关键词可第二轨黄/粉字（如 `Señor`、`contrato`） |

### 6.4 配乐

- **仅使用 TikTok 商用音乐库（Commercial Music Library）或素材自带已授权原声。**  
- 禁止：未授权流行歌、网盘无出处 BGM、他人成片扒带。  
- 每条成片在发布清单记录：`音乐名 / 作者 / TikTok 音乐 ID / 使用日期`。

### 6.5 封面规范（交画眉）

| 项 | 规范 |
|---|---|
| 尺寸 | 1080×1920（或平台封面比例，导出同竖版） |
| 构图 | 人物情绪脸居中偏上；底部留字幕安全区 |
| 文字 | 西语钩子 ≤6 词，粗体描边；可中英双语时仍以西语主文案为准 |
| 风格 | 甜宠：暖粉/金色；复仇：冷蓝/黑金；同一合集色系统一 |
| 禁止 | 假播放量、假「Parte 99」、未授权明星脸、误导「全集成片」 |

### 6.6 标题 + 话题标签模板

**标题公式：**  
`[情绪emoji] [钩子短句西语] | [题材标签]`

示例：
- `💍 Un año de mentiras… ¿o de amor? | Contrato matrimonial`
- `😱 Mi novio “estudiante” era el dueño | Identidad oculta`
- `🔥 Me echaron de casa. Volví como su abogada | Venganza`

**标签池（每帖 4–6 个，勿堆砌）：**  
`#DramasCortos #NovelaVertical #AmorYPoder #ContratoDeAmor #IdentidadOculta #VenganzaFamiliar #TikTokDrama #SerieCorta`

英文标签仅作辅（如 `#ShortDrama`），主标签保持西语以匹配受众。
