## 0. 原则

1. **金额只读私有 SoT**，公开 `workspace.json` 中金额字段为 `null`，看板/实算禁止用脱敏后的公开列表当真数。
2. **不编造**：目标未填 → 完成率显示「—」；缺日期 → 按下方归属规则回退并打数据质量标记。
3. **币种**：源表无 `currency` 字段，看板默认 **CNY**；若日后多币种，先在私有数据加字段再改口径。
4. **付款状态与项目状态解耦**（与字段规范 §3.4 一致）：`paymentStatus` 不替代 `status`。

---

## 1. 字段映射（工作台 camelCase）

| 业务含义 | 字段 | 类型约定 |
|---|---|---|
| 合同总额 | `totalAmount` | 数值；缺省按 0 参与求和，并记「缺/零」质量项 |
| 定金 | `depositAmount` | 参考用，不单独上主指标卡 |
| 已付 | `paidAmount` | 累计已收（非单笔流水） |
| 未付（源） | `unpaidAmount` | 优先使用；应 ≈ `totalAmount − paidAmount` |
| 付款状态 | `paymentStatus` | `pending` / `deposit_paid` / `fully_paid` |
| 服务开始 | `serviceStartDate` | **合同归属日优先** |
| 服务结束 / 截止 | `serviceEndDate` / `deadline` | 逾期判定；`deadline` 优先于 `serviceEndDate` |
| 创建时间 | `createdAt` | ISO；转 Asia/Shanghai 取日历日作回退归属 |
| 项目状态 | `status` | 逾期风险辅助，不进金额公式 |

## 2. 公共派生量

对每条项目 \(i\)：

| 符号 | 定义 |
|---|---|
| \(T_i\) | `totalAmount` 可解析为数则用该值，否则 `0`（并记 non_numeric / 缺省） |
| \(P_i\) | `paidAmount` 同上 |
| \(U_i\) | 若 `unpaidAmount` 可解析则用之；否则 \(\max(T_i - P_i, 0)\)。若二者差绝对值 \(> 0.01\)，以字段值为准展示，并记 `unpaid_mismatch` |
| **合同归属日** \(D_i\) | ① `serviceStartDate` 的日历日；② 否则 `createdAt` 转 Asia/Shanghai 的日历日；③ 否则空（该条不进「本月/本年」合同类指标，进质量问题） |
| **截止日** \(E_i\) | `deadline` 优先，否则 `serviceEndDate`；皆空则无逾期判定资格 |

**零金额占位**：\(T_i = 0 \land P_i = 0\)。计入项目数，合同额贡献为 0；**不得**因 `paymentStatus=pending` 把它们算作「有待收合同」。

## 3. 指标卡定义（建议总览摆放）

建议 2 行：

- **行 A（存量健康）**：全库已收 · 全库待收 · 全库逾期 · 有金额项目数  
- **行 B（期间业绩）**：本月合同额 · 本年合同额 · 本月/本年目标完成率（合同）· 本月/本年回款完成率  

或压缩为 6～8 卡：本月合同额、本年合同额、全库已收、全库待收、全库逾期、本年合同目标完成率、本年回款目标完成率、有金额项目数。

### 3.1 全库合同额

\[
\sum_i T_i
\]

### 3.2 全库已收

\[
\sum_i P_i
\]

说明：源数据无「收款发生日」，**已收按项目累计余额**，不能做成真正的「本月回款流水」。期间「已收」见 §3.6。

### 3.3 全库待收（存量）— 主卡「待收」

\[
\sum_i U_i
\]

仅当 \(U_i > 0\) 时该条为待收项目。零金额占位贡献 0。

### 3.4 全库逾期（存量）— 主卡「逾期」

\[
\sum_{i:\, U_i > 0 \,\land\, E_i \ne \emptyset \,\land\, E_i < \text{基准日}} U_i
\]

基准日 = 看板刷新当日（Asia/Shanghai 日历日）。

**逾期风险（非金额卡，可黄点）**：\(U_i > 0\) 且 \(E_i\) 空且 `status=delivered` 且 `paymentStatus ≠ fully_paid`。只计数/列表，不并入逾期金额，避免无截止日期时虚增逾期。

### 3.5 本年 / 本月合同额

设基准日所属年 \(Y\)、月 \(M\)。

- **本年合同额**：\(\sum_{i:\, D_i.\mathrm{year}=Y} T_i\)
- **本月合同额**：\(\sum_{i:\, D_i.\mathrm{year}=Y \,\land\, D_i.\mathrm{month}=M} T_i\)

无 \(D_i\) 的项目：**不计入**期间合同额。

### 3.6 本年 / 本月已收、待收、逾期（期间切片）

在无收款流水日的前提下，期间切片 = **合同归属落在该期间的项目**上的 \(P_i\) / \(U_i\) / 逾期 \(U_i\) 合计。

| 指标 | 公式 |
|---|---|
| 本年已收 | \(\sum_{D_i\in Y} P_i\) |
| 本年待收 | \(\sum_{D_i\in Y} U_i\) |
| 本年逾期 | \(\sum_{D_i\in Y \,\land\, \text{逾期条件}} U_i\) |
| 本月已收 / 待收 / 逾期 | 同上，限制到 \(Y{-}M\) |

> 产品注意：总览「待收/逾期」**优先用全库存量**（§3.3–3.4）；期间待收仅作同期新签合同的回款进度，避免与存量混淆。

### 3.7 目标完成率

目标来自 `targets.local.json`（§4）。未填或为 `null` → 完成率 **「—」**，禁止用 0 或假目标。

| 指标 | 公式 |
|---|---|
| 本年合同目标完成率 | 本年合同额 / `websiteProjects.yearly.contractTarget`（目标 \(>0\)） |
| 本年回款目标完成率 | 本年已收 / `websiteProjects.yearly.collectionTarget` |
| 本月合同目标完成率 | 本月合同额 / 对应 `monthly[].contractTarget` |
| 本月回款目标完成率 | 本月已收 / 对应 `monthly[].collectionTarget` |

### 3.8 辅助卡（可选）

| 指标 | 公式 |
|---|---|
| 有金额项目数 | \(\lvert\{i: T_i > 0\}\rvert\) |
| 零金额占位数 | \(\lvert\{i: T_i=0 \land P_i=0\}\rvert\) |
| 全款结清数 | `paymentStatus = fully_paid` 条数 |
| 定金未结清数 | `deposit_paid` 且 \(U_i>0\) |

## 4. 目标业绩配置

### 4.1 路径与忽略

- 路径：`超级工作台应用/data/private/targets.local.json`

```json
{
  "version": 1,
  "updatedAt": null,
```

## 5. 缺失值与异常处理

| 情况 | 处理 |
|---|---|
| 金额字段 `null`/空 | 按 0 求和，记质量项 |
| 非数字金额 | 该字段按 0，记 `non_numeric` |
| `unpaid` 与 `total−paid` 不一致 | 展示以 `unpaidAmount` 为准，记 `unpaid_mismatch` |
| 无 `serviceStartDate` | 归属回退 `createdAt`，记 `date_fallback_createdAt` |
| 无归属日 | 不进本月/本年合同类指标 |
| 无截止日但有待收 | 不进逾期金额；可进「逾期风险」列表 |
| `fully_paid` 但已付 < 总额或仍有待收 | 记质量项，金额仍按字段实算 |
| `pending` 且已付>0 | 记质量项 |
| 目标 `null` | 完成率「—」 |

## 6. 已知数据风险（口径层，不含金额）

实算时若出现下列现象，看板应展示数据质量条，而不是静默当「经营真相」：

1. **大量 `totalAmount=0` 且 `paymentStatus=pending`**：多为占位/未录入合同价，不是「全员欠款」。  
2. **`createdAt` 同日批量**：多为系统导入日；在补齐 `serviceStartDate` 前，本月/本年合同额会接近全库合同额，**期间对比失真**。  
3. **无收款流水日**：无法做真实「本月回款」；只能用合同归属切片或全库累计已收。  
4. **无币种字段**：一律按 CNY 展示并注明假设。
