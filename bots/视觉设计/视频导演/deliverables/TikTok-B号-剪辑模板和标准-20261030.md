# TikTok B号｜剪辑模板和标准

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-30（Asia/Shanghai） |
| 账号 | B号 · The Mill Rules |
| 配套脚本 | `bots/视觉设计/视频导演/files/tiktok_b_edit.sh` |
| 素材根目录 | `/workspace/media/tiktok/B号/`（**视频/音频不进 git**） |

## 目录约定

```
/workspace/media/tiktok/B号/
  raw/     # MiniMax 或实拍原始镜头
  work/    # 中间文件（拼接、缩放）
  music/   # 已获授权的配乐（WAV/MP3）
  subs/    # 英文字幕 .srt
  out/     # 最终导出（供上传）
```

---

## 1. 前 3 秒钩子规则

1. **第 0–1 秒**：必须有视觉冲击或冲突信息（验布灯亮 / 推水杯 / 甩样布 / 人影入画），禁止黑场开场超过 0.5s。
2. **第 1–3 秒**：必须出现一句钩子（对白或大字幕），句式优先：指控 / 反问 / 倒计时 / 禁忌信息。  
   例：`That's not our fabric.` / `Prove it. Now.` / `48 hours.`
3. **禁止**：开场自我介绍、品牌口号、产品参数口播、缓推空镜超过 2s。
4. **自检**：把成片前 3 秒静音播放——仍能看懂「出事了」才算过关。

---

## 2. 字幕样式（英文字幕）

| 项 | 标准 |
|---|---|
| 语言 | English only |
| 位置 | 底部安全区，距底边约 12–15%（避开 TikTok UI） |
| 字体 | 无衬线粗体（脚本默认 `DejaVu Sans Bold`；有 Inter/Montserrat 可替换） |
| 字号 | 相对 1080 宽约 42–48px（ffmpeg `FontSize=48`） |
| 颜色 | 主字白色 `#FFFFFF`；描边/阴影深色，保证冷调画面可读 |
| 单行 | ≤ 42 字符；优先两行内说完一句 |
| 时间轴 | 对白超前 ≤0.1s，滞后 ≤0.2s；钩子句可略提前强调 |
| 文件 | `subs/epXX.srt`，UTF-8 |

**SRT 示例（Ep1 钩子段）：**

```srt
1
00:00:00,800 --> 00:00:03,000
11:47 PM. Inspection tomorrow.

2
00:00:05,000 --> 00:00:07,500
Run it again.
```

## 3. 配乐与版权注意

1. **只用**：TikTok Commercial Music Library、已购授权库、或自有/委约原创；**禁止**未授权流行歌、影视原声。
2. 每次选用记录：曲名、来源、授权范围、到期日 → 写入 `notes/music-license-log.md`。
3. 混音：对白/环境声为主；BGM 压低到约 **-18 ~ -22 dB** 相对对白（脚本默认 music 音量系数 `0.18`）。
4. 反转卡点：允许 0.3–0.6s 近乎静音 + 单音效，再回 BGM。
5. 发布前在 TikTok 草稿检测版权提示；若黄标则换曲重导。

## 4. 画面与导出参数（TikTok）

| 项 | 标准 |
|---|---|
| 分辨率 | 1080×1920（9:16） |
| 帧率 | 30 fps（与素材一致时可 24，但导出统一 30） |
| 视频编码 | H.264 `yuv420p`，`profile=high`，`level=4.1` |
| 码率 | 目标 ~8–12 Mbps（CRF 18–20 或 `-b:v 10M`） |
| 音频 | AAC 48 kHz，立体声，~192 kbps |
| 像素格式 | yuv420p（兼容性） |
| 时长 | 单集成片 30–60s；试运营目标 45–55s |
| 文件名 | `out/ep01_That's_Not_Our_Fabric_tiktok.mp4` |

缩放策略（脚本已实现）：`scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920`（先铺满再中心裁切）。

## 5. 标题与话题标签公式

**标题公式：**

```
[钩子原句] | Ep{N} · The Mill Rules
```

例：`That's not our fabric. | Ep1 · The Mill Rules`

**标签公式（8–12 个）：**

```
#shortdrama #workplacedrama #mystery #textile #factory #supplychain #zhanfa #fyp
+ 本集关键词 1–2 个（如 #waterproof #sampling #plotwist）
+ 可选 #verticaldrama #dramatok
```

**简介末行（可选）：** `More: zhanfatextile.com`（主页链接优先）

## 8. 一键剪辑用法

```bash
# 在仓库内
bash bots/视觉设计/视频导演/files/tiktok_b_edit.sh \
  --episode ep01 \
  --title "That's_Not_Our_Fabric" \
  --clips /workspace/media/tiktok/B号/raw/ep01_shot01.mp4 \
          /workspace/media/tiktok/B号/raw/ep01_shot02.mp4 \
  --srt /workspace/media/tiktok/B号/subs/ep01.srt \
  --music /workspace/media/tiktok/B号/music/bed_loop.wav \
  --music-vol 0.18
```

输出：`/workspace/media/tiktok/B号/out/ep01_That's_Not_Our_Fabric_tiktok.mp4`

也可用 `--demo` 在本机生成测试素材并跑通全流程（不调用 MiniMax）。
