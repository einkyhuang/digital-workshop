# 外贸客户开发与跟进邮件实战

## 适用场景

适合中国外贸业务员、外贸跟单、外贸新人，在以下场景中使用：

- 给不同国家/地区客户写首次开发信。
- 回复简单询盘、模糊询盘、精准询盘。
- 做范围报价、精准报价、报价单式报价、成本解释式报价。
- 客户失联、已读未回、未读未回时的跟进催促。
- 样品确认、样品运费沟通、寄样通知、测样跟进。
- 客户压价、比价、谈价僵局、最终逼单。
- 发送 PI、确认银行账号、委婉催款、索要水单。
- 船期确认、发货通知、单据确认、正本寄送、到港提醒。
- 售后问题沟通、客诉处理、节日祝福与客户维系。

本技能强调：先判断客户类型与阶段，再选择对应邮件策略；不盲目报价、不盲目降价、不硬催，尽量通过确认需求、展示价值、提供方案来推进订单。

## 核心原则

1. **因地制宜**：根据客户所在国家/地区调整表达重点和沟通习惯。
2. **投其所好**：不同客户群关心点不同，要优先呈现对方最在意的价值。
3. **互动引导**：开发信和回盘可用提问降低客户回复门槛。
4. **先确认，再报价**：需求不清时不要盲目给出精准价格。
5. **信息透明前置**：船期、发货、单据、到港等关键节点主动提前同步。
6. **价值主导**：谈价时不只比单价，要比质量、认证、售后、使用成本和总成本。
7. **让步必须绑定条件**：降价、运费补贴、账期优惠都应与数量、付款、有效期等条件挂钩。
8. **委婉催款**：催款要有合理理由，避免生硬催讨。
9. **安全优先**：银行账号必须反复确认，防止邮件诈骗和信息篡改。
10. **舒适跟进**：跟进客户时避免压迫感，用提醒、案例、备料、市场信息等自然理由保持联系。
11. **不卑不亢**：保持专业、友好、长期合作姿态，不过度乞求订单，也不情绪化。

## 可执行步骤

### 1. 开发信

1. 先判断客户背景：
   - 客户国家/地区。
   - 客户类型：贸易商、批发商、零售商、使用商、制造商、分销商等。
   - 是否有人介绍、是否使用竞品、是否已有采购历史。

2. 按国家/地区调整侧重点：
   - **北美客户**：开门见山，强调效率和安全感；使用企业邮箱；可提及接受 PayPal；尽量用 “We” 代表公司，而不是过多使用 “I”。
   - **欧洲客户**：强调质量、交期、认证、售后和合同安全感；可列举大客户案例或认证资料。
   - **中东客户**：用简单英文，提供细节；插入产品图片、规格、参数；可强调低价、品牌合作经验和交友式沟通。
   - **南美客户**：用简单单词和提问式表达；强调免费样品、OEM、价格、质量或交货优势。
   - **澳洲客户**：表达交友和合作意愿；强调价格优势，可说明含运费或完税后的价格思路；突出长期可靠、小批量灵活。

3. 选择开发信类型：
   - **询盘式开发信**：适合不知道客户具体需求时。对贸易商可问是否销售某类产品；对使用商可问其是制造商还是分销商。
   - **开门见山式开发信**：适合有熟人介绍、知道客户使用竞品、能提出替代方案时使用。可点出客户痛点，提出更优方案，并用客户见证或采购量增强可信度。

4. 邮件内容建议包含：
   - 简短开头，说明来意。
   - 客户最关心的利益点。
   - 公司优势：经验、认证、工厂、证书、大客户合作情况。
   - 明确行动号召：请客户回复需求、索取目录、确认型号或安排样品。
   - 可附资料：畅销产品目录、数据表、工厂信息、证书信息。

5. 避免群发式空泛表达，每封邮件至少有一个针对客户国家、类型或产品的具体点。

---

### 2. 回盘

1. 先判断询盘类型。

2. **简单询盘**：客户只问价格或只有一句话。
   - 不要立即盲目报价。
   - 结构：感谢客户兴趣 → 简述公司优势 → 用 “in order to” 或类似表达引出具体需求 → 承诺确认后再报价。
   - 可反问：用途、材质、硬度、比例、颜色、数量、包装、认证、交期、目标市场等。

3. **精准询盘**：客户已经说明数量、定制、包装、Logo、交期等。
   - 先感谢并推荐主打产品或现有方案。
   - 对客户提出的每一项要求逐条回应。
   - 明确：颜色、印刷、Logo 文件、样品、样期、包装、起订量、交期、付款方式。
   - 不要遗漏客户提到的任何细节。

4. **模糊询盘**：客户表达泛泛，缺少采购细节。
   - 不要轻易放弃。
   - 列出产品主要分类。
   - 发送包含工厂详情、销售图表、客户分布、产品优势等内容的公司简介。
   - 引导客户说明具体需求。
   - 涉及大客户案例时，避免直接暴露可被竞争对手挖角的客户全名，可用市场排名、行业类别或区域代表代替。

---

### 3. 报价

1. **范围报价**：适合客户直接询价但需求不明确。
   - 先给出价格区间。
   - 说明产品种类、规格、数量、用途不同会影响价格。
   - 列出需要客户确认的问题。
   - 承诺客户确认后提供精准报价和运输方案。

2. **精准报价**：适合客户需求已经明确。
   - 核心要素至少包括：
     - 贸易术语，如 EXW、FOB、CIF 等。
     - 价格。
     - 数量。
     - 付款方式。
     - 包装方式。
     - 运输方式。
     - 交期。
     - 报价有效期。
     - 汇率说明。
   - 附加要素可包括：
     - 海关编码。
     - 产品保质期。
     - MOQ/起订量。
   - 若需要报运费，主动询问目的港。

3. **报价单式报价**：适合客户在多个型号之间选择。
   - 感谢询盘并简述公司优势。
   - 说明畅销款或主推款。
   - 对比不同型号的关键差异，如兼容性、连接方式、功能、适用场景。
   - 附价格单，请客户选择意向型号。

4. **成本报价**：适合价格谈判僵局或客户压价很狠。
   - 可展示成本构成，说明价格合理性。
   - 强调无法通过降低质量来迎合目标价。
   - 提供替代方案，例如不同配置、不同材料、不同数量、不同交期。
   - 不要过度披露成本细节，避免泄露商业机密。
   - 不在客户刚询价时就用成本报价。
   - 涉及专利、技术机密或核心配方时谨慎使用。

5. **报价后跟进**：
   - 客户未查看邮件时，可重发或提醒查看。
   - 提醒时可保留原邮件主题，方便客户查找。
   - 不要只问“Did you receive my email?”，应补充新的价值点或下一步动作。

---

### 4. 失联跟进

1. 对重要邮件可使用邮件追踪工具，例如 Readnotify 或同类工具。
   - 用于判断客户是否打开邮件。
   - 注意追踪工具有时效限制，过期结果不可靠。

2. 客户未读且电话承诺回复但 3-4 天无消息：
   - 使用迂回提醒。
   - 给客户台阶，例如公司周会需要更新进度、生产排期需要确认、价格或原料有变化。
   - 避免直接质问。

3. 客户已读但一周未回：
   - 排查可能原因：价格、付款方式、交期、运费、MOQ、样品测试结果、内部审批、个人事务。
   - 可选跟进角度：
     - 直接询问：请客户说明顾虑。
     - 商业角度：价格、交期、库存、汇率、船期。
     - 朋友角度：关心客户近况，降低业务压力。
     - 方案角度：列出可选方案，让客户选择。
   - 目标是引导客户说出真实顾虑，而不是逼客户马上成单。

4. 客户因家庭变故、公司事务或市场困难暂停项目：
   - 先关怀，再保持轻度联系。
   - 可分享市场信息、行业信息、新品信息。
   - 不要强行推进订单。

---

### 5. 样品

1. **寄样前技术确认**：
   - 工作温度。
   - 湿度或使用环境。
   - 催化剂混合比例。
   - 颜色。
   - 其他影响样品适用性的技术参数。

2. **寄样前地址确认**：
   - 公司名。
   - 详细地址。
   - 联系人。
   - 电话。
   - 手机号。
   - 邮编。
   - 若客户不愿提供私人电话，可借确认地址、快递联系、紧急物流等理由委婉询问手机号。

3. **样品费与运费沟通**：
   - 可说明样品免费，运费到付。
   - 客户犹豫时，可申请运费各付一半。
   - 可用长期采购节省金额来说服客户承担小额运费。
   - 若客户仍有顾虑，可根据公司政策考虑运费返还或订单后抵扣等方式。
   - 支持 PayPal 等小额支付方式可降低付款门槛。

4. **寄样前视觉确认**：
   - 发送包装图片。
   - 发送样品标签。
   - 发送清关发票或交货单。
   - 必要时发送视频。
   - 客户确认无误后 1-2 天内发出。

5. **发货后追踪**：
   - 提供快递单号。
   - 提供查询网址。
   - 快递显示签收后，主动联系客户确认是否收到、包装是否完好。

6. **测样跟进**：
   - 提醒客户保留标签、COA、附件等资料。
   - 若材料有特殊测试要求，提醒分开测试或隔离测试。
   - 客户收到样品后不要立刻强催结果。
   - 可在约两周后自然询问反馈。
   - 可用旺季提前备料、生产排期、同行客户反馈等理由跟进。
   - 优先使用 “follow” 式自然跟进，而不是 “push” 式催促。

### 6. 谈价

1. 先判断客户谈价意图：
   - 盲目比价。
   - 只看单价。
   - 认可产品但卡在价格。
   - 已接近成交，需要最后推动。

2. **重心转移法**：适合客户未测样或尚未了解产品，只拿低价施压。
   - 承认市场上可能有更低价格。
   - 强调差异化优势：质保、认证、售后、实物细节、稳定供货、大客户使用案例。
   - 邀请客户先测样。
   - 可承诺达到一定订单量后给予特价。

3. **价值主导法**：适合客户只看初始单价。
   - 不单纯比单价。
   - 计算单位使用成本、产出比、总花费。
   - 用数据说明：看似单价高，但达到相同产出时总成本更低。

4. **间接让步法**：适合单价已到底线，但双方有合作意愿。
   - 不轻易降单价。
   - 可用运费补贴、付款条件优化、交期优先等方式让步。
   - 要求客户增加订单量、提高定金比例或确认更快下单作为交换。

5. **直接让步法**：适合信任已建立、进入最后成交阶段。
   - 可给出底价或破盘价。
   - 必须绑定条件：数量、包装、付款方式、交期、报价有效期、汇率条件。
   - 可提醒汇率波动、原料上涨、年底调价等，制造合理紧迫感。
   - 语气保持从容，不乞求，不威胁。

6. 所有谈价邮件都应做到：
   - 有理有据。
   - 不空喊“质量好”。
   - 不无条件降价。
   - 不让步没有交换条件。
   - 保持长期合作姿态。

### 7. 收款

1. 发送 PI 时：
   - 列明完整银行信息：受益人、账号、银行名称、SWIFT 代码。
   - 明确提醒客户：不要相信任何账号变更通知。
   - 说明如有账号变更，必须通过既定电话或既有联系方式再次确认。

2. 电话双重确认：
   - 询问客户预计转账时间。
   - 告知会通过电话再次核对账号。
   - 不把账号安全只寄托在邮件上。

3. **价格保留催款**：适合原材料已备齐或价格即将变化。
   - 告知原料已备齐或当前价格可保留。
   - 请客户在某个期限前付款，以锁定价格。
   - 理由要真实、合理，不要随意虚构。

4. **金额巧合催款**：适合需要委婉确认水单。
   - 可说明财务收到一笔金额相近款项。
   - 请客户确认是否为其汇款。
   - 顺势请客户提供水单。
   - 没有相似金额入账时不要使用该方式。

5. 催款总体原则：
   - 避免生硬说“Please pay now”。
   - 给客户合理理由和台阶。
   - 保持礼貌但明确。

---

### 8. 运输

1. **船期沟通**：
   - 列明截关日、ETD、ETA。
   - 可用船期节点催促客户尽快确认订单。
   - 可结合旺季、库存、生产排期说明紧迫性。

2. **发货通知**：
   - 发货当天通知客户。
   - 附货物实拍图片。
   - 用表格列明货物细节：品名、数量、包装、体积、重量、唛头等。

3. **单据信息收集**：
   - 发货后提前确认提单收货人和通知人。
   - 不要等到最后才收集，避免改单。

4. **收款与备货反馈**：
   - 收到水单后及时核实并回复客户。
   - 实际到账后再次确认，并告知备货完成时间和发货计划。
   - 未核实到账前，不轻易承诺生产或发货。

5. **单据一次性确认**：
   - 将提单、产地证、发票、装箱单等打包一次性发给客户确认。
   - 避免今天确认提单、明天确认发票、后天再改装箱单。
   - 保证单据之间信息一致。

6. **特殊清关风险处理**：
   - 对海关政策较严格的国家，应谨慎处理发票金额和申报方式。
   - 如涉及免费样品，可按已将样品成本平摊入产品单价的思路处理。
   - 发票抬头、单价等信息应与形式发票或客户要求保持一致。

7. **正本单据寄送**：
   - 寄出前扫描所有原件。
   - 提供快递单号、查询网址、预计送达时间。
   - 确认客户签收后提醒其妥善保管正本提单。

8. **到港前提醒**：
   - 到港前一周再次提醒客户。
   - 附目的港代理联系方式。
   - 提醒客户准备清关、提货，并在收货后检查包装和数量。

---

### 9. 售后

1. 按客户类型分类回访：对使用商询问产品满意度、技术问题与改进建议；对贸易商了解当地销量、消费者反馈、竞品情况与价格竞争力。
2. 售后沟通中加入价值输出：分享海外市场见闻，并结合当地市场趋势推荐已在其他市场验证过的新产品，邀请客户评估。
3. 建立客户返单频率档案：记录客户历史采购周期，发现超过预期未返单时，主动询问采购计划并排查流失原因。
4. 利用节点促进返单：在公司周年庆促销前提供折扣信息，或在长假前提醒客户提前备货、确认订单。
5. 对老客户进行二次开发：询问老贸易商其终端客户是否需要玻纤、造型泥、PU等关联产品，借已有信任拓展新品类。

### 10. 客诉

1. 收到客诉后第一时间回复：告知客户已收到反馈，并说明正在核查留样或相关情况。
2. 明确责任归属：如属己方责任，应大方道歉并承诺负责处理；如非己方责任，应说明情况并协助客户补救，不滥用道歉。
3. 给出明确时间节点：向客户承诺具体回复时间，例如24小时内回复、48小时内提供解决方案。
4. 排查期间持续安抚：向客户表示会将损失降到最低，请客户耐心等待处理进展。
5. 列出需客户协助确认的信息清单：请客户向最终用户核实具体细节，便于定位问题。
6. 补救措施实施后主动跟进：询问客户措施是否可行、问题是否改善。
7. 问题解决后说明预防措施：告知客户已优化的内部流程，例如仓库包装流程调整，避免问题复发。
8. 征求客户对改进措施的建议：进一步挽回信任并巩固合作信心。

### 11. 节日祝福

1. 安排周末互动：每月发送2次周末问候，搭配图片与生活化内容，如出差见闻、城市特色，并主动询问客户当地文化。
2. 长假前确认业务事项：在圣诞等长假前，与客户确认紧急重要问题，并明确对方具体放假时间。
3. 提前准备大客户礼物：针对3A等高价值客户，提前一周准备并寄出具有中国特色的礼物。
4. 按客户文化和市场分类发送祝福：对美国客户可在感恩节前推出促销活动；对过圣诞的客户发送圣诞与新年祝福；对不过圣诞的客户仅发送新年问候。
5. 节假日邮件中补充己方安排：告知客户己方放假时间，并提供紧急联系电话，避免假期业务中断。

## 检查清单

- [ ] 是否判断了客户国家/地区和客户类型？
- [ ] 开发信是否根据当地习惯调整了重点？
- [ ] 北美客户是否使用企业邮箱，并注意用 “We” 代表公司？
- [ ] 欧洲客户是否强调了认证、质量、售后或合同安全感？
- [ ] 中东客户是否使用简单英文，并附图片、规格、细节？
- [ ] 南美客户是否使用提问式表达，并提到免费样品或 OEM？
- [ ] 澳洲客户是否体现交友意愿、价格优势和小批量灵活性？
- [ ] 简单询盘是否没有盲目报价，而是先反问具体需求？
- [ ] 精准询盘是否逐条回复了客户所有问题？
- [ ] 模糊询盘是否展示了公司实力并引导客户提出需求？
- [ ] 公司简介中的大客户信息是否做了防挖角处理？
- [ ] 范围报价是否给出价格区间并引导确认需求？
- [ ] 精准报价是否包含贸易术语、价格、数量、付款方式、包装、运输、交期、有效期、汇率？
- [ ] 是否补充了海关编码、保质期、MOQ 等附加信息？
- [ ] 成本报价是否提供了替代方案并避免泄露核心机密？
- [ ] 报价后是否对未读邮件进行了重发或主题提醒？
- [ ] 是否使用追踪工具判断客户是否已读？
- [ ] 客户未读时是否使用了迂回提醒而不是生硬催促？
- [ ] 客户已读未回时是否排查了价格、付款、交期、MOQ 等原因？
- [ ] 寄样前是否确认温度、湿度、配比、颜色等技术参数？
- [ ] 寄样地址是否包含公司、地址、联系人、电话、手机号、邮编？
- [ ] 样品运费承担方式是否已经说清楚？
- [ ] 寄样前是否发送包装图、标签、清关资料或视频供确认？
- [ ] 发货后是否提供单号和查询网址？
- [ ] 签收后是否主动确认客户收到且状态良好？
- [ ] 测样跟进是否自然，而不是强催结果？
- [ ] 谈价时是否先判断客户是比价、看单价、僵局还是接近成交？
- [ ] 是否把焦点转移到质量、认证、售后、使用成本等价值上？
- [ ] 降价或让步是否绑定数量、付款、有效期等条件？
- [ ] 最终底价是否设置了有效期和汇率/成本提醒？
- [ ] PI 是否完整列明银行信息？
- [ ] 是否提醒客户不要相信账号变更通知？
- [ ] 是否计划电话二次确认账号？
- [ ] 催款是否有合理理由，而不是生硬催讨？
- [ ] 船期邮件是否包含截关日、ETD、ETA？
- [ ] 发货通知是否附图片和货物明细表格？
- [ ] 是否提前确认提单收货人和通知人？
- [ ] 是否在水单核实和实际到账后才推进生产或发货？
- [ ] 提单、产地证、发票、装箱单是否一次性打包确认？
- [ ] 特殊国家或免费样品场景是否注意了申报和金额处理？
- [ ] 正本单据寄送是否提供扫描件、快递单号和查询方式？
- [ ] 到港前是否提醒客户并附目的港代理信息？
- [ ] 售后/客诉是否先收集证据和确认事实？
- [ ] 售后/客诉是否给出可执行方案和时间节点？
- [ ] 节日祝福是否轻量、自然、不硬推销？

## 常见错误

- 开发信不分国家，用同一套话术发给所有客户。
- 给北美客户使用免费邮箱，或过多使用 “I” 而不是 “We”。
- 给中东客户缺少细节，没有图片、规格或使用复杂英文。
- 给南美客户没有使用提问式，也没有提到免费样品或 OEM。
- 给澳洲客户没有体现交友意愿、价格优势或小批量灵活性。
- 对一句话询盘直接盲目报价，丧失需求确认和谈判主动权。
- 轻易放弃模糊询盘，没有用公司实力引导客户。
- 在公司简介中直接暴露大客户全名，增加被竞争对手挖角风险。
- 精准报价遗漏贸易术语、付款方式、有效期、汇率等关键信息。
- 客户刚询价就使用成本报价，或过度披露成本细节。
- 客户未读报价邮件后不跟进，或跟进时没有提醒邮件主题。
- 不使用追踪工具，盲目猜测客户是否已读。
- 客户已读未回时只发干瘪催促，不给客户台阶。
- 忽略追踪工具时效，导致误判客户状态。
- 客户遇到家庭或公司变故时仍强行推进订单。
- 寄样前不确认温度、湿度、配比、颜色等技术参数。
- 收件信息不完整，尤其是缺少手机号，影响紧急联系。
- 寄样前不做包装、标签、清关资料视觉确认。
- 客户刚收到样品就强催测试结果，造成压迫感。
- 没有提醒客户特殊材料需要分开测试或隔离测试。
- 客户一压价就降价，没有价值说明或交换条件。
- 只空泛说“质量好、服务好”，没有具体数据或案例。
- 降价没有绑定数量、付款、有效期等条件。
- 最终底价没有设置有效期，也没有制造合理紧迫感。
- 谈价姿态失衡，过度乞求订单或情绪化回应。
- 发送 PI 后不反复确认银行账号，也不提醒防诈骗。
- 只通过邮件确认账号，没有电话二次核对。
- 催款过于生硬，没有价格保留、金额确认等合理理由。
- 船期邮件没有写清截关日、ETD、ETA。
- 发货通知没有图片和货物明细。
- 分批次让客户确认单据，增加错误和沟通成本。
- 未核实水单或实际到账就承诺生产或发货。
- 单据之间信息不一致，影响客户清关。
- 售后或客诉未先收集证据就急于承诺或推责。
- 节日邮件强行推销，破坏客户维系氛围。

### 后三章要点备忘
- 9. 售后
  - 必须区分使用商和贸易商，避免用同一套话术回访。
  - 要记录客户返单周期，对超期未返单客户及时排查原因。
  - 售后不能只催订单，还要分享市场信息并推荐适配新品。
  - 公司促销或长假前应提前提醒老客户备货，避免错失订单。
  - 老贸易商有二次开发价值，可顺势拓展关联产品。

- 10. 客诉
  - 客诉必须第一时间响应，避免客户情绪恶化并降低配合度。
  - 道歉要看责任归属，非己方责任时不可滥用 Sorry。
  - 要给客户明确时间节点，如24小时回复、48小时给方案。
  - 排查时需要列出具体信息清单，请客户协助向终端核实。
  - 补救后要跟踪效果，并说明预防复发的流程改进，形成闭环。

- 11. 节日祝福
  - 周末祝福频率不宜过高，控制在每月2次，内容要生活化且可互动。
  - 必须核实客户是否过相关节日，避免向不过圣诞的国家发送圣诞祝福或礼物。
  - 圣诞等长假前要确认紧急事项和客户假期，防止业务延误。
  - 高价值客户可提前一周寄送中国特色礼物以维护关系。
  - 节假日祝福邮件应写明己方放假时间和紧急联系方式。
