# SmartPlan Hub - 智能日程与项目管理系统 (Mac 联通版)

一款专为 macOS 用户打造的**智能项目管理与日程管理联通系统**。结合 AI 自然语言对话能力，实现与 macOS 原生「提醒事项 (Apple Reminders)」的无缝双向自动同步。

---

## ✨ 核心功能亮点

### 1. 🤖 AI 智能对话 & 日程自动匹配
- **自然语言输入**：例如直接输入 *"明天下午3点跟进外贸客户报价，准备样品清单"* 或 *"周五前完成系统代码重构"*。
- **自动解析关键要素**：自动提取任务标题、规划截止日期、具体时间段、紧急优先级（高优/普通/低优）。
- **智能项目匹配**：根据语义与关键词自动将任务分配至对应的项目（如「外贸客户跟进」、「智能日程管理」等）。
- **免配置开箱即用**：内置离线高精度中文 NLP 规则引擎；同时支持无缝对接 **DeepSeek / OpenAI / 通义千问 / Kimi / Ollama** 等大模型。

### 2. 🔄 与 Mac 提醒事项深度双向联通
- **正向同步（看板/AI ➔ Mac 提醒事项）**：
  - 在 Web 看板或 AI 对话中创建日程时，系统通过原生 AppleScript 自动推送到 Mac 提醒事项（默认清单：`AI 智能日程`）。
  - 带提醒时间、备注与优先级。
- **反向同步与自动归档（Mac 提醒事项 ➔ 自动识别并归档到看板）**：
  - 当你在 Mac、iPhone、Apple Watch 或用 Siri 新建了一条提醒事项时；
  - 系统后台自动感知并交由 AI 分析任务内容；
  - **自动推断归属项目，并整理归档到看板对应的项目列中**！
- **状态实时联动**：
  - 在 Mac 提醒事项中勾选完成，看板对应卡片自动标记为「已完成」；
  - 在看板中拖拽推进状态，提醒事项同步更新。

### 3. 📋 现代化多视图看板
- **项目看板 (Kanban)**：待办 (To Do)、进行中 (In Progress)、已完成 (Done)、整理归档 (Archived) 四列视图，支持按项目筛选与快速搜索。
- **日程日历 (Calendar)**：今日日程、明日规划、未来计划、未排期积压等多维度时间轴。
- **项目中心 (Projects)**：项目色标、描述、完成率进度条、关联待办统计。
- **双向同步中心 (Sync Center)**：实时呈现双向同步日志与流水审计。

### 4. 🌐 客户定制网站档案库 (直达线上网址 & 本地跳转)
- **自动归档分类**：已全面接入 `/Users/ky/Desktop/定制网站-客户版`，智能扫描并按照 **「进行中」**、**「已交付」**、**「功能基础建设」**、**「已暂停/挂了」** 自动归类。
- **线上网址直跳**：点击网站名称或网址链接，即可在浏览器直接打开生产或预览网站。
- **本地项目一键跳转**：点击「在访达中打开」，一秒穿梭定位到 macOS 本地源码目录；支持一键在代码编辑器中打开！
- **实时同步与编辑**：支持一键重新扫描目录，随时修改补充网址与客户备忘。

## 🚀 快速启动

在终端运行以下一键脚本即可启动并自动打开浏览器：

```bash
./start.sh
```

或使用标准 npm 命令：

```bash
# 启动生产服务（构建前端并启动服务端）
npm run build
npm start

# 或开发模式
npm run dev
```

启动后在浏览器访问：**`http://localhost:3300`**

## ⚙️ 系统配置说明

点击顶部的 **「系统设置」** 页面即可进行个性化配置：

1. **AI 模型引擎配置**：
   - 支持自定义 `API Base URL`、`API Key`、`模型名称`。
   - 预设支持 DeepSeek、OpenAI、阿里云通义千问、Kimi、Ollama 本地大模型。
   - *（注：未填写 Key 时，系统将自动使用内置启发式引擎平替，依然可以正常解析日期与项目）*
2. **Mac 提醒事项配置**：
   - 默认同步清单：`AI 智能日程`（初次运行时系统已自动在你的 Mac 提醒事项中建好此清单，清晰隔离不混乱）。
   - 自动轮询频率：支持 10秒 / 20秒 / 60秒 自由调整。

## 🛠 技术架构

- **前端**：React 19 + Tailwind CSS + Lucide Icons + Vite
- **后端**：Node.js + Express 5 + SQLite (`better-sqlite3` 高并发 WAL 模式)
- **Mac 联通**：原生 AppleScript (`osascript`) 进程桥接，零第三方云端账号依赖，隐私与本地数据安全完全自控。
